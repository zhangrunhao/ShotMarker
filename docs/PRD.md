# ShotMarker 产品需求文档

日期：2026-05-01
状态：草案
技术方向：SwiftUI

## 产品概述

ShotMarker 面向进行投篮训练的篮球爱好者。用户训练时使用 Apple Watch 记录主观认为值得保留的时刻；训练结束后，训练记录同步到手机端。手机端以训练记录为入口，用户选择对应训练视频后，应用根据视频开始时间和打点时间自动剪辑训练集锦，并保存到系统相册。

产品核心价值是减少训练复盘的视频整理成本，让用户不需要手动拖动长视频，也能快速得到每次投篮前后的小片段。

## 目标用户

- 经常进行个人投篮训练的篮球爱好者。
- 希望保留训练片段、复盘动作或分享训练成果的用户。
- 训练时愿意佩戴 Apple Watch，并能在值得保留的时刻快速打点的用户。

## 产品感受

- 专业：流程稳定、剪辑结果可信、时间对齐逻辑清晰。
- 克制：界面不做社交化和娱乐化堆叠，优先提供打点、选择视频、生成集锦这条主路径。

## P0 范围

### Watch 端训练打点

- Watch 端展示一个主按钮。
- 长按按钮开始训练。
- 训练中双击按钮记录一次时间戳。
- 每次打点记录当前绝对时间。
- 打点代表用户主观认为值得保留的训练时刻。
- 记录成功后，Watch 端通过震动提醒用户。
- 再次长按按钮结束训练。
- 每次训练形成一条训练记录。
- 长按结束训练后，训练记录向手机端批量同步。
- 如果同步失败，训练记录保留在 Watch 本地并标记为待同步，后续继续重试。

### 手机端首页

- 手机端首页展示训练记录列表。
- 首页不展示本地视频列表。
- 训练记录列表展示日期、时间、打点数量、是否已剪辑、同步状态。
- 用户点击一条训练记录后，进入该记录的集锦生成流程。

### 视频选择

- 用户选择训练记录后，手机端提示用户选择训练视频。
- P0 只能选择苹果手机录制的标准格式视频。
- P0 只能选择自带开始时间的视频。
- 如果视频缺少开始时间或格式不支持，应用应阻止继续生成，并提示用户重新选择视频。
- P0 不需要把已选择视频保存为本地视频列表。

### 自动剪辑

- 手机端根据视频开始时间和训练记录计算每个打点在视频内的相对时间。
- 默认每个打点生成一个片段：打点前 10 秒到打点后 3 秒。
- 如果片段开始时间早于视频开始，则从视频第 0 秒开始。
- 如果片段结束时间超过视频结束，则截断到视频结束。
- 只处理落在视频时长范围内的打点。
- 多个打点片段重叠时不进行合并，每次都按照对应打点独立剪辑。
- 集锦需要保留原视频音频。
- 多个片段按时间顺序合成为一个集锦视频。

### 保存到相册

- P0 不提供生成前视频预览。
- 用户确认训练记录和视频后，应用直接生成集锦。
- 集锦视频生成后自动保存到系统相册。
- 保存前需要处理相册权限。
- 保存成功后，将该训练记录标记为已剪辑。
- 保存失败时应给出明确错误提示，并允许用户重试。

## P1 范围

- 支持导入不带开始时间的视频。
- 选中视频和训练记录后，允许用户根据视频手动调整训练记录的整体偏移。
- 允许用户调整每个打点前后剪辑时长，例如从默认的前 10 秒、后 3 秒改为自定义值。

## P2 范围

- 手机端直接录制视频，并在录制过程中实时剪辑成为片段。
- 支持片段选择、组合和过场动画。
- 支持多机位同时剪辑。
- 加入登录、社区分享等在线能力。

## 核心用户流程

### Watch 端流程

1. 用户打开 Watch 端应用。
2. 用户长按主按钮开始训练。
3. 用户训练过程中双击按钮，为值得保留的时刻打点。
4. 每次打点成功后，Watch 端震动反馈。
5. 用户长按主按钮结束训练。
6. Watch 端生成本次训练的训练记录。
7. Watch 端将训练记录批量同步到手机端。

### iPhone 端流程

1. 用户打开手机端首页。
2. 首页展示已同步的训练记录列表。
3. 用户选择一条训练记录。
4. 应用提示用户选择对应训练视频。
5. 用户从相册选择苹果手机录制的标准格式视频。
6. 应用校验视频是否带有开始时间。
7. 应用根据视频开始时间和训练记录生成剪辑任务。
8. 应用直接导出集锦视频并保存到相册。
9. 保存成功后，首页对应训练记录显示为已剪辑。

## 非功能要求

- P0 优先本地处理，不依赖登录和服务端。
- 视频和打点数据默认保留在设备内，降低隐私风险。
- 剪辑结果应可解释：用户能知道有效打点数量，以及哪些打点因超出视频范围被忽略。
- 时间计算需要处理时区、夏令时和设备时间误差，内部应优先使用绝对时间。
- UI 风格保持克制，主流程中减少非必要入口。

## 已确认产品决策

- 首版 App 以训练记录为中心，不需要视频列表页面。
- iPhone 首页展示训练记录列表。
- 用户选择训练记录后，再选择对应训练视频。
- Watch 端只提供一个主按钮。
- Watch 端长按按钮开始或结束训练。
- Watch 端训练中双击按钮完成打点。
- 打点成功后，Watch 端通过震动提醒用户。
- 打点代表用户主观认为值得保留的训练时刻。
- 每次训练形成一条训练记录。
- 长按结束训练后，训练记录向手机端批量同步。
- P0 当前只支持选择苹果手机录制的标准格式视频，并要求视频自带开始时间。
- 多个打点片段重叠时不合并，每个打点独立生成片段。
- 集锦视频需要保留原视频音频。
- P0 不需要生成前视频预览，确认训练记录和视频后直接生成并保存。
