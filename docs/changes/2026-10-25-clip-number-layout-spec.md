# 片段独立序号布局与操作列表

- 日期：2026-10-25。
- 状态：操作列表、模式切换、连续继承和不同布局分别保留均已由用户确认，进入实施；其余补充细节为作者据现有契约确定的实现选择，不冒充用户单独确认。尚未完成，不作为测试或构建通过记录。
- 范围：iPhone 片段编辑中的序号位置、字号与操作模式；不包含整个视频补点、语音识别或逐段透明度。

## 目的与当前事实

让每个审核片段保存自己的序号位置和大小，在实际视频预览上调整；平时收起次要操作，避免序号与取景争抢同一个拖动手势。

2026-10-25 对当前代码的只读核查结果：

- `HighlightClipEditorView` 显示取景倍率按钮和“恢复原画面”，没有序号叠加或操作模式。
- `MarkerLabelSettingsView` 只编辑任务统一样式，`MarkerLabelStyle` 保存位置、字号和两种透明度。
- 审核工作副本、任务存储及最终片段已有独立取景，没有独立序号布局；正常事务写 schema 3。
- 最终编号按保留打点连续计算；审核候选编号、原始打点编号与导出序数不是同一个概念。
- 导出固定使用第一段保留来源的正向完整尺寸作为画布，其他来源按比例适配。标签最后叠加在该画布上，不随取景放大。

## 已选择的交互方案

讨论过三种入口：直接拖动小序号、当前页面切换操作模式、独立大画面编辑页。

直接拖动省一次点击，但小标签不易选中，且现有画面拖动与缩放已用于取景；独立页面提供更大空间，但会打断逐段审核。用户选择当前页面的互斥操作模式，并明确用可收起的操作列表承载入口。

### 用户已确认

1. 原“恢复原画面”按钮的位置改为展开/收起操作列表的按钮。
2. 展开后在其下方显示一排操作：取景操作开关、恢复原画面、序号操作开关。
3. 初始取景操作开启，序号操作关闭。
4. 开启序号操作时关闭取景操作；预览下方出现序号字体大小滑杆，并允许拖动序号位置。
5. 关闭序号操作后自动开启取景操作。
6. 主动开启取景操作时自动关闭序号操作，字号滑杆随之隐藏。
7. 取景操作可以主动关闭；两种操作可以都关闭，但不能同时开启。
8. 收起列表只隐藏那排按钮，不改变当前操作模式；序号操作开启时，字号滑杆仍显示。

### 状态转换

| 当前模式 | 点击操作 | 新模式 | 字号滑杆 |
| --- | --- | --- | --- |
| 取景 | 关闭取景操作 | 无空间操作 | 隐藏 |
| 取景或无空间操作 | 开启序号操作 | 序号 | 显示 |
| 序号 | 关闭序号操作 | 取景 | 隐藏 |
| 序号或无空间操作 | 开启取景操作 | 取景 | 隐藏 |
| 任意 | 展开/收起操作列表 | 不变 | 由模式决定 |

“恢复原画面”是一次性重置取景值，不切换模式、不改变范围，也不改变序号布局。取景关闭时禁止通过它修改取景。开关控制是否可以编辑，不控制标签是否显示或导出。

## 补充交互规则（实现选择）

- 列表默认收起；展开按钮显示当前模式的简短状态，使收起后仍能辨别“取景”“序号”或“操作关闭”。
- 现有取景减号、倍率、加号保留原位；只在取景模式且媒体可用时可操作。操作列表入口不因处于序号模式而禁用。
- 三个操作按钮使用“开启/关闭取景”“恢复原画面”“开启/关闭序号”等明确文案。普通字号优先同排；窄屏或辅助字号可换行，不压缩可点击区域。
- 序号模式下，在实际成片画布区域内拖动相对位移即可移动序号，不要求准确命中小字，不把触点绝对坐标直接变成序号中心。画布外不接受序号拖动。
- 序号显示实际导出大小；仅编辑时显示选中轮廓。即使文字和底色全透明，编辑轮廓仍可见且可操作；关闭操作后轮廓隐藏，透明度不被修改。
- 字号沿用现有画布短边 4%–16% 范围，滑杆按 1 个百分点调整，显示当前百分比。无需小缩放手柄，不给序号另设双指缩放手势。
- 开启序号操作以及开始空间调整时暂停播放；结束手势或切换模式后不自动播放。播放按钮仍可主动播放；播放不改变模式。
- 无空间操作模式下，画面不截获用于空间调整的手势，页面保持可滚动。序号模式下取景拖动、双指缩放、倍率按钮及取景无障碍动作均不可修改取景。
- “恢复原画面”仅在取景操作开启且媒体可用时可点击，已经是原画面时也禁用；序号模式和无空间操作模式下不能通过该按钮修改取景。
- 模式和展开状态只属于当前审核会话，不作为片段业务数据。连续确认和手动跳转时保留模式及列表状态；退出审核后再次进入，恢复默认取景模式、列表收起。
- 未载入有效画布或媒体不可用时，保留操作状态和相应界面，但禁用空间编辑；不阻止已有排除、返回和导航能力。
- 提供序号四向移动和字号的无障碍调整，使用与手势相同的边界规则；操作模式、开启/关闭和禁用原因不只依赖颜色表达。

## 每段保存与默认设置（实现选择）

每段的布局是字号比例、横向中心、纵向中心组成的一个快照；只改字号后确认，也保存该时刻的位置。不拆成三个独立的“是否跟随默认”开关。

- 新片段及旧任务缺少布局时，使用本任务当前默认序号位置和字号。文字和底色透明度始终沿用任务统一样式。
- 进入编辑器后使用工作副本。只切换模式、展开或收起列表不修改数据、不产生未保存提示。
- 用户调整位置或字号时，与范围、取景一起标记未保存；改回进入时的有效值后清除相应修改状态。
- 点击保留或排除时，原子保存范围、取景、包含状态和当前有效序号布局；排除项也保留布局，方便重新打开后改回保留。
- 保存成功才进入下一段；写盘失败或版本冲突保留工作副本，不发布导航或覆盖其他片段。
- 返回或手动跳转时沿用现有继续调整/放弃提示；放弃恢复入口基线。关闭序号操作与收起列表都不是保存操作。
- 已保存布局优先于任务默认；以后修改任务默认位置或字号，只影响还没有保存过布局的片段。任务透明度更改仍作用于所有片段。
- 改默认前后时间或视频配置时，序号布局随安全保留的确认项一起保留；重新规划的新默认项不带覆盖值。
- “重置全部片段”经现有二次确认后清空逐段布局，恢复任务当前默认；提示文案应包含序号调整会被重置。
- 本次不增加单段恢复序号默认、批量应用布局、动画位置或逐段透明度设置。

## 连续审核继承（用户已确认）

与取景一致：目标已有保存布局始终优先；只有同来源、通过成功保留或排除进入紧邻下一段、且目标没有保存布局时，临时沿用上一段有效布局。跨来源或手动打开任何片段时，只使用目标保存值或任务默认。

临时继承自身不制造未保存提示；确认时保存为该段快照。发生主动调整后按入口有效值判断未保存；返回入口有效值后清除。导航携带目标身份与来源身份，消费时重新校验，保存失败不产生继承。

## 最终合并与预览

用户已确认在现有相邻合并条件上增加“有效序号布局相同”。不同位置或字号分别保留各段完整范围，与不同取景一致；范围重叠时可重播，输出总时长按实际片段累计。相同布局继续按已有来源、取景、相邻关系和间隔规则合并。

以下为基于该决定的实现选择：

- 未保存布局与明确保存但数值相同的布局，在视觉/合并比较中等价；解析时使用任务当前默认，不能仅比较可选值是否相同。
- 总览的片段数、时长与相邻关系提示使用同一个最终规划器；不同布局时显示“序号布局不同，分别保留”，不伪报生成时合并。
- 序号是最终输出的 `number/total` 或 `start-end/total`，不借用页面顶部候选编号。将当前工作副本代入完整任务规划，预览显示其所属最终片段的编号。
- 已排除片段显示“序号”占位文本供布局调整，明确标记为排除预览；它不计入最终导出。重新保留时按最终编号重新计算文本宽度和边界。
- 预览先构造最终成片画布，再把当前来源的取景按比例适配进去，最后叠加标签；布局坐标与字号均相对最终画布，包含成片自身的黑边，不相对播放器外部留白。
- 预览的画布比例来自当前规划第一段保留来源的完整正向尺寸。全排除时仅以当前来源尺寸显示排除预览；不把这个临时画布当作生成规格。
- 异步加载画布与当前来源元数据使用任务/来源/加载代次校验，不能由迟到结果改变当前片段；元数据不可用时不以假尺寸保存布局。
- 位置是左上原点的归一化标签中心；使用实际标签外框大小限制边界，字号或编号变化后重新限制显示位置。保存期望中心，显示阶段的边界限制不偷偷改写其他片段。
- 预览和导出共用字体、文本尺寸、内边距和边界计算；长编号在最大字号下仍完整可见，必要时按同一比例缩小整个标签以适配画布，不能仅裁掉文字。
- 一个审核片段即使包含多个原始打点，也共用一套布局；本次不拆分该片段内部的打点。

## 数据与实现边界（实现选择）

- 新增 `MarkerLabelPlacement`，保存 `fontSizeRatio`、`normalizedCenterX`、`normalizedCenterY`；有效范围分别为 0.04…0.16、0…1、0…1，要求全部有限。
- 为审核工作项和持久化片段增加可选布局字段；缺字段表示任务默认。UI 的移动可统一到 0.00001 精度，读取已合法值不主动舍入或改写。
- 编码无覆盖值时省略字段；显式 null、缺失布局成员、非数值、非有限值和越界值按损坏数据处理，不静默补成默认。旧执行缺布局字段时使用其执行快照内的样式。
- 正常事务写 schema 4，兼容读取 1/2/3/4；旧文件仅加载或无变化操作不写盘、不变 revision。高版本继续走未来版本保护，避免旧客户端保存时静默丢掉逐段字段。
- 规划最终片段时解析完整有效布局；新执行捕获不可变逐段布局及任务透明度。运行中的导出不读取之后的任务或全局样式。
- 合成器按每段布局产生叠加指令；标签图片缓存不能仅以文本为键，需包含影响图像的字号、透明度与画布尺寸，位置在每段指令中计算。
- 保留现有原子写盘、版本冲突、旧成片保留、停止与取消清理边界；不改变 Watch、数据世代、训练打点、Analytics 或网络披露。
- 已停用的旧组合确认 Store 不新增正式使用路径；仅为共享模型保留必要兼容。
