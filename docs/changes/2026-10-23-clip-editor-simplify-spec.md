# 片段编辑精简与有符号时间范围

日期：2026-10-23
状态：按用户手机试用后的五项明确要求实施；下列边界由实施者依据现有契约确定。
基线：main `7cd8eb3`；工作分支 `codex/clip-editor-simplify`。

## 目标与用户要求

个人投篮训练中优先看视频、慢放、拖动范围和连续保留/排除，减少低频信息占用。

1. 删除单独占行的“沿用上一段取景”，保持已经确认的继承行为。
2. 把当前位置/起点/终点/时长四列压缩成单行片段内播放进度，例如 `0.0 / 6.9 秒`，使用小号次要文字。起止仍可通过时间轴及其可访问性操作读取。
3. 删除编辑页和总览的上一操作结果提示与撤销入口；修改决定通过全部片段重新打开并保留/排除。清除仅用于这些入口的 View 代码；底层已存在的完整状态恢复与加载保护不因界面删除而放宽。
4. 删除单段“恢复默认范围”入口，保留时间轴拖动、取景的“恢复原画面”和任务配置中的重置全部。
5. 前后秒数允许零和负值：`start = marker - before`、`end = marker + after`。前 11 / 后 -2 表示打点前 11 秒至前 2 秒，共 9 秒。

## 实施选择与约束

- 用户允许删除继承提示或移到状态后；选择删除，避免状态行在长文案/大字号下拥挤。时间信息使用片段内相对进度，避免重复显示长绝对秒数。
- 保留/排除固定底栏只留下操作按钮、必要的保存进度/错误；普通字号播放按钮应完整可达，大字号允许页面滚动，主要按钮及底部跳转不被遮住。
- 两个偏移控件范围均为 -20…20 秒、1 秒步进，保持现有最大绝对范围。前后两项均须有限、在范围内且相加至少 1 秒。允许编辑时暂时形成无效组合，明确提示并禁用进入审核/提交配置，不偷偷修改另一项。
- 配置展示实际相对起止及长度，负“后”值表达打点之前，负“前”值表达打点之后。默认值仍为前 9、后 4。
- 继续选择包含该打点的来源视频，不自动跨来源借片段；超出该来源的部分截到有效边界，完全不相交的默认片段不生成。来源内裁切及最短片段规则保持既有行为。
- 只改默认偏移必须继续保留安全的已确认人工范围、保留状态和取景。新默认窗口与来源无交集时也不能丢失这些确认；有新合法默认基线则更新，没有则保留原基线。有效确认项仍可进入审核。
- 新负值若由旧客户端按 schema 2 读取，会被旧校验判为损坏。正常任务写入升级 schema 3，兼容读取 1/2/3，读取及无变化事务不改文件；旧客户端走未来版本只读保护。无 epoch 重置、无源视频改写。
- 不变更取景继承、独立保存、导出、编号、时间轴手势和媒体加载代次保护。不扩展为语音剪辑。

## 验证

- 真实界面普通/最大字号检查单行进度、播放与保留/排除可达，底部全部片段跳转；删除的提示/按钮不可见。修改原撤销 UI 用例为通过底部重开、更改决定和加载切换的实际用户流程，保留底层撤销/迟到加载单元覆盖。
- 前11/后-2 → 偏移-11…-2；前0/后4、前4/后0和前-2/后11可保存并生成正确范围。零长、反向、非有限和越界组合不可创建/提交。
- UserDefaults、任务文件与快照负值往返；schema1/2无变化读取不升级，成功写入3，未来版本保护；已确认取景/人工范围在默认窗口移出来源时仍保留。
- 相关状态/规划/存储测试与真实配置 UI 回归后，运行一次完整 iPhone suite；独立审查整体变更，按结果更新 current 后归档。
