# 片段序数样式默认收起规格

- 日期：2026-09-02
- 状态：已实现并完成自动验证；独立 UI 人工验收待补
- 范围：iPhone“生成集锦”页面的片段序数样式区域

## 背景

当前页面在选择视频后直接展示序数预览、位置拖动区域和三个调节项，占用较多纵向空间。序数样式已经作为 `ClipSettings.markerLabelStyle` 通过 `ClipSettingsStore` 保存在本地，但设置区域没有收起能力。

## 目标

- 选择视频后仍显示“片段序数”区域，但样式调整内容默认收起。
- 用户展开后可以继续预览、拖动位置并调整字号、文字不透明度和黑底不透明度。
- 用户修改过的数值和位置继续保存在本地；再次进入页面时使用上次保存的样式。

## 交互设计

- `TrainingSessionHighlightView` 在“片段序数”Section 中显示标题为“样式调整”的系统 `DisclosureGroup`。
- 页面首次创建时，`DisclosureGroup` 的 `isExpanded` 为 `false`。
- 展开后呈现现有 `MarkerLabelSettingsView`，不修改其中的预览、拖动、滑杆或辅助功能行为。
- 同一次页面生命周期内允许用户自由展开和收起；收起不会重置当前样式。
- 离开后重新进入“生成集锦”页面时再次默认收起。展开状态本身不写入本地。

## 数据与持久化

- 不新增存储键、模型字段、远端字段或 Analytics 事件。
- `clipSettings` 继续在页面创建时通过 `ClipSettingsStore.shared.load()` 加载。
- `clipSettings` 变化时继续通过现有 `.onChange` 保存完整设置。
- `markerLabelStyle` 中的字号、横纵归一化位置、文字不透明度和黑底不透明度必须一起恢复。
- 创建集锦任务时继续保存当时的 `ClipSettings` 快照；本变更不改变已创建任务。

## 边界与兼容性

- 未选择视频时不显示片段序数区域，与当前行为一致。
- 生成任务期间，展开后的设置内容继续遵循现有禁用状态。
- 旧版没有样式字段的本地设置继续由现有兼容解码补入默认样式。
- 不增加“恢复默认值”入口，也不记忆展开状态。

## 验收标准

1. 选择视频后可见“片段序数”与“样式调整”，预览和滑杆默认不可见。
2. 点击“样式调整”后显示现有预览与三个调节项，再次点击后收起。
3. 展开、修改数值或拖动位置、收起并再次展开，当前值和位置不变。
4. 修改样式后退出页面并重新进入：区域仍默认收起；展开后显示上次保存的数值和位置。
5. `ClipSettingsStoreTests` 继续证明完整样式可由新的 store 实例恢复。
6. iPhone 测试与 Release Simulator 构建通过。

## 验证策略

- 本仓库没有 UI Test 或 SwiftUI 视图检查依赖；经用户确认，本次不为单个系统 DisclosureGroup 引入新测试框架。
- 使用现有 `ClipSettingsStoreTests` 自动验证本地样式的数值和位置持久化。
- 使用编译、完整 iPhone 测试和 Release Simulator 构建验证集成。
- 使用 iOS Simulator 人工检查默认收起、展开、收起后状态保留，以及重新进入后的样式恢复；无法完成的人工项必须明确记录为未验证。
