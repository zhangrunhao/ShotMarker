# ShotMarker 产品事实

- 最后复核：2026-09-03
- 产品范围：iPhone + Apple Watch 本地优先训练打点与视频集锦

## 当前结论

当前产品流程已经覆盖 Watch 训练打点、可靠同步、iPhone 视频准备、集锦片段审核与范围调整、逐片段长期确认和相同组合恢复、可预览的片段序数样式、持久化集锦生成和手动保存。赛后本地语音分析仍是已确认但尚未实现的产品决定。

## 核心用户流程

1. 用户在 Apple Watch 长按开始训练。
2. 用户在精彩时刻双击屏幕或转动数码表冠打点。
3. 用户长按结束训练，Watch 将训练记录可靠同步到 iPhone。
4. 用户在 iPhone 打开训练记录并选择对应视频。
5. App 校验视频时间范围，准备需要从 iCloud 下载的视频。
6. App 根据打点生成默认合并片段，并恢复同一训练内容与同序视频组合中已经确认的片段。
7. 用户可以直接使用默认值生成，也可以逐片段调整、确认保留或确认排除；单片段确认成功后连续打开后续默认片段。
8. 用户在图集确认生成后，App 以当前精确片段快照创建持久化集锦任务并返回首页。
9. 任务完成后，用户可以播放本地结果并手动保存到系统相册。

## Apple Watch

- 长按控制训练开始和结束。
- 双击或数码表冠累计转动达到阈值时创建打点，并提供触觉反馈。
- 使用 HealthKit workout session 保持训练期间的运行状态。
- 未确认送达的训练记录保存在本地 outbox；收到 iPhone ACK 后删除。
- 同步失败会按间隔重试，不因一次失败丢弃训练记录。

## iPhone

- 首页展示训练记录和集锦任务。
- 支持删除、JSON 导入导出和多条训练记录合并。
- 最多选择 20 个视频。
- 视频按创建时间、时长和打点覆盖范围校验；不可用视频显示具体原因。
- iCloud 视频支持准备进度、暂停和恢复。
- 选择视频后，“片段序数”中的“样式调整”默认收起；展开后以第一项视频的静态完整画幅缩略图预览序数。预览不播放视频，缩略图缺失时显示不阻止生成的占位画面。
- 用户可以拖动全局序数位置，并调整文字大小、文字不透明度和黑底不透明度；数值和位置自动保存在本地，之后进入页面并展开设置时继续使用上次保存的样式。
- 审核图集明确区分“默认”和“已确认”，并分别显示保留、排除或视频不可用状态；合并卡片作为整体处理，原始打点保持固定且不写回训练记录。
- 默认卡片不是待办门槛，可以直接参与“确认并生成”。全局前后时长变化只重算默认卡片，不覆盖已确认范围或排除状态。
- 单片段编辑器支持范围播放、起点/终点拖动、整体平移、独立播放头、0.5 秒精调和恢复默认范围；编辑只改变工作副本，确认写盘成功后才发布到图集，失败可原地重试。
- 未确认改动返回时提示“放弃本次调整？”；放弃恢复打开编辑器时的确认值或默认值。确认成功后只打开当前卡片之后的第一个默认片段，跳过已确认片段，末尾不循环。
- 排除、范围变化和最终合并会实时更新保留打点数、排除打点数、最终片段数与预计总时长。
- 集锦任务串行执行，支持排队、取消、重启、中断恢复、播放和清理。
- 已完成视频保存在 App 本地；用户可以重复尝试保存到相册。

## 剪辑规则

- 默认范围：打点前 9 秒、打点后 4 秒。
- 用户设置保存在本地；前置范围为 0–20 秒，后置范围为 1–20 秒。
- 每个打点匹配第一个覆盖其时间的已选视频。
- 同一视频中重叠或间隔不超过 1 秒的片段会合并。
- 片段边界会裁剪到视频实际范围。
- 审核触摸结果与确认值按 0.1 秒规范化；视频至少 1 秒时片段最短为 1 秒，更短视频只能使用完整有效范围。
- 最终只合并图集原始顺序相邻、同一视频、仍保留且重叠或实际间隔不超过 1 秒的片段；被排除或不同视频的卡片中断合并链。
- 导出保留可用音轨、视频方向，并添加 `number/total` 或合并片段 `start-end/total` 序数标签。
- 序数样式默认字号为完整画面短边的 10%，中心点为左上原点的 `(15%, 10%)`，文字不透明度为 100%，黑底不透明度为 60%。字号可调范围为 4%–16%，两种不透明度可独立调为 0%–100%。
- 序数中心点会按每个标签的实际尺寸限制在完整画面内；一个任务的所有片段使用任务创建时固化的同一组样式。

## 数据与网络

- ShotMarker 将训练记录、任务状态、沙盒任务文件和日志保存在本地；所选源视频及用户手动保存的成片由系统照片库管理，是否通过 iCloud 同步取决于系统设置。
- 逐片段确认保存在独立的本地版本化 JSON 中；只在训练内容与视频身份、数量和选择顺序全部一致时恢复。它不写入训练记录或任务历史，也不跨设备同步。
- 序数样式只保存在本地用户设置和任务 JSON 中，不新增 Analytics 事件或远端字段。
- 新任务在本地 JSON 中保存 `clipPlanVersion = 1` 与非空 `confirmedSegments`；排队、重启和中断恢复都使用同一份片段与样式快照。两个字段都缺失的旧任务继续使用旧规划，不一致或损坏的新快照明确失败。
- 审核缩略图、胶片帧、播放器和编辑工作副本只存在于本地内存或系统媒体访问链路；逐片段确认也只在 App 沙盒内持久化，不上传、不新增 Analytics 事件。
- 当前没有登录或账号；训练记录、视频及其他业务内容不会存入业务服务器，也没有跨设备云同步。
- Release iPhone 会发送四个固定产品事件和精简错误/崩溃信息；详细边界见 [产品埋点](analytics.md) 与 [发布状态](release.md)。
- Watch 不发送 Analytics 或 GlitchTip 数据。

## 有效产品决定

- 训练记录只表达训练和打点事实，不保存“已剪辑”状态。
- 集锦任务作为独立本地队列持久化。
- 集锦生成与保存相册分离，保存由用户手动触发。
- 片段序数样式是集锦级全局设置，创建任务后由任务快照固定，不随之后的默认设置变化。
- 集锦创建前必须经过默认合并片段的图集审核：卡片默认保留，可整体排除或单独调整范围；原始训练打点不修改，确认后的精确片段由任务快照固定。该决定已经实现，完整设计见 [已归档 Change](../archive/2026-09/2026-09-02-highlight-clip-review-spec.md)。
- 用户可以把单个片段长期确认为保留或排除；再次选择内容完全相同的训练记录与同序视频时恢复确认值，其余片段保持默认且不阻止生成。该决定已经实现，设计与验证见 [已归档 Change](../archive/2026-09/2026-09-03-highlight-clip-confirmation-spec.md) 和 [验证记录](../archive/2026-09/2026-09-03-highlight-clip-confirmation-validation.md)。
- iOS 语音口令采用赛后、本地分析路线，但该能力尚未实现。完整设计见 [活跃 Change](../changes/2026-07-29-ios-voice-command-marking-spec.md)。
