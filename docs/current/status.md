# ShotMarker 当前状态

- 最后本地复核：2026-10-27（埋点增强；测试与外部事实分别使用下列入口的验证日期）。
- 工程版本：1.3.1（Build 4）；产品范围为 iPhone + Apple Watch。

## 当前范围

ShotMarker 提供 Watch 训练打点与同步、训练 JSON 导入/导出与多选管理、iPhone 视频准备、独立可编辑集锦任务、逐片段范围/取景/序号审核、串行生成和手动保存相册。任务固定训练快照，停止或后续修改保留旧成片；数据世代 1 首次启动清理旧本地业务数据，不迁移。

当前首页仍为训练记录，集锦任务与训练记录同页。任务卡片通过“编辑任务”按钮进入配置；逐段取景与序号操作已实现。当前没有语音识别、语音事件或球员统计，没有登录、账号或业务云同步。

手机侧埋点已补来源、自用标记及同步/生成/保存的尝试与结果；业务存储与调度、Watch 发送侧保持原样。App 和网站改动均已合并并推送 main；网站已部署，App 新版正在打包送审。不能用新增分类重新判定历史使用。
