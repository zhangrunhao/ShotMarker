## 当前覆盖

- 训练存储、JSON 导入导出、合并/删除、Watch 同步、outbox 和固定 cutover 的旧载荷 ACK 保护。
- 视频准备、范围/编号/合并、播放、媒体释放、导出、相册、日志、GlitchTip、Analytics 与隐私契约。
- 有符号范围的零值/负值/非法组合、无效默认值隔离；默认窗口移出来源时保留合法人工确认和取景。
- 任务 schema 1/2/3/4、独立训练身份、revision/无变化事务、损坏和未来版本保护；文件复制、回滚及受控路径。
- 配置协调、串行队列、停止/后台、迟到生成回调及输出移动/提交失败时保留旧成片；Photos 实际保存与本地状态更新的事件边界。
- 审核紧邻导航、末项不循环、确认失败保留调整、未保存跳转提示；底层撤销 API 与事务互斥有测试，正式界面通过重开片段修改决定。
- 相邻关系复用最终规划，包含反向范围、跨源、排除与合并桥接；同取景/布局合并及不同取景/布局的完整重叠输出。
- 取景与布局的保存、目标已保存值优先、同源临时继承、手动恢复、入口 dirty、失败隔离、元数据代次和重置；非法/null 字段与兼容解码。
- 24 项 UI 基线包括 7 项任务、6 项审核、7 项真实媒体导航/取景/序号/加载隔离及 4 项时间轴。合成 H.264/AAC 覆盖横竖屏、旋转、多来源、真实像素及音轨；accessibility5 环境检查播放、决定按钮及导航可达性。
- 缩略图保留上限 64 项，退出后 AVAsset 弱引用释放和帧数据清理；审核不逐片段导出。
- 模拟旧 epoch 升级的业务文件/缓存/临时文件/偏好和旧日志目录清理、Photos 保留、第二次启动保留新数据；Watch 临时目录 outbox 重置。
- 播放器无效加载释放、迟到元数据/观察回调、定位完成乱序与实际回首后重播；服务加载期间场景变化及 inactive 不覆盖后台状态。
- 日志正常写入执行 14 天/30 MB 清理、旧目录清理与自定义目录隔离；Watch 授权迟到、结束保存期间快速重启、过期回调与拒绝/不可用保护。
